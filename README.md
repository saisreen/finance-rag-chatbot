# Finance FAQ Chatbot

## Project Overview

A Retrieval-Augmented Generation (RAG) chatbot that answers consumer finance questions using CFPB content.

## Features

- Web crawler
- Text cleaning
- Chunking
- OpenAI Embeddings
- ChromaDB
- Semantic Search
- GPT-4.1-mini
- React Frontend
- FastAPI Backend

## Architecture

React
   ↓
FastAPI
   ↓
Retriever
   ↓
ChromaDB
   ↓
GPT
   ↓
Answer
